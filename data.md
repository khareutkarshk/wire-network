# CORE VALUE PROPOSITION

Headline:
The Problem Isn't Messaging. It's Ownership.

Description:
Blockchains operate as sovereign environments. As applications move across ecosystems, liquidity fragments, execution becomes uncertain, and ownership can become difficult to determine.

Wire introduces a shared coordination layer designed to make cross-chain financial state explicit, queryable, and recoverable.

Key Points:

1. Shared Financial State
A coordination layer defines what happened across connected ecosystems.

2. Deterministic Execution
Transactions follow a defined lifecycle with explicit outcomes.

3. Native Asset Security
Assets remain on their original chains while Wire coordinates ownership rights.

4. Defined Recovery
Failed execution follows an explicit recovery path rather than becoming an ambiguous state.

# HOW IT WORKS

Headline:
From Cross-Chain Uncertainty to Explicit Outcomes

Traditional Model:

- Assets move between chains
- Bridges introduce additional custody assumptions
- Applications maintain their own recovery systems
- Failed transactions can become difficult to reconcile
- Liquidity becomes fragmented

Wire Model:

- Assets remain native to their home chains
- Ownership rights are coordinated through Wire
- Transactions follow a defined lifecycle
- Outcomes are explicit
- Financial state becomes queryable
- Recovery is part of the execution model

Outcome States:

PENDING
Transaction initiated

ROUTING
Optimal execution path determined

EXECUTING
Transaction being processed

SETTLED
Execution successfully completed

RECOVERING
Defined recovery process initiated
