# Deploying wire.network

Static Astro build. `pnpm build` writes everything to `dist/`; any static host works (Netlify, Vercel, Cloudflare Pages, S3 + CloudFront).

## Before the first deploy

1. **Early-access endpoint (required).** Set `PUBLIC_EARLY_ACCESS_ENDPOINT` in the host's build environment (see `.env.example`). The form POSTs `{"email", "source"}` as JSON. Formspree, Basin, a CRM webhook or your own API all work. Without it the form tells visitors sign-up is unavailable, and the build logs a warning.
2. **Domain.** `site` in `astro.config.mjs` is `https://wire.network`. Canonical URLs, the sitemap, `robots.txt` and share images all derive from it. Change it if the site launches on another domain.
3. **404.** `dist/404.html` exists. Netlify, Vercel and Cloudflare Pages pick it up automatically; S3/CloudFront needs it set as the error document.

## URL rules

- Pages build as folders and the canonical URL ends in a slash: `/developers/`, `/whitepaper/`. Canonicals, sitemap and internal links all use that form; `/developers` still works. Leave the host's trailing-slash setting on its default (or "always add").
- `/system/` is an internal design-system page: `noindex`, disallowed in `robots.txt`, left out of the sitemap.

## What ships for SEO and sharing

- Per-page `<title>`, description, canonical, Open Graph and Twitter tags; share image `public/og.png` (1200 x 630).
- JSON-LD: Organization on every page, WebSite on `/`, TechArticle on `/whitepaper/`.
- `sitemap-index.xml` (generated by `@astrojs/sitemap`), `robots.txt`, `site.webmanifest`, favicons (SVG, 32px PNG, Apple touch icon).

## Optional, per host

Security headers (`Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, a Content-Security-Policy) are set in the host's config. If you add a CSP, allow `connect-src https://raw.githubusercontent.com` (the whitepaper reader loads the latest PDF from GitHub) and your early-access endpoint, and `worker-src 'self' blob:` for the PDF reader.
